# スクリーンショット画像置き場

このフォルダには、Figmaプラグイン公開申請時に使用するスクリーンショット画像を配置してください。

## 要件

### ファイル形式
- PNG または JPG
- 推奨サイズ: 1200x900px 以上
- ファイル名: わかりやすい名前（例: 01-save-kit.png, 02-apply-kit.png など）

### 推奨スクリーンショット内容

1. **01-save-design-kit.png**
   - デザインキットを保存する画面
   - 「デザインキットを保存」セクションが展開されている状態

2. **02-select-kit.png**
   - デザインキットを選択するドロップダウン画面
   - 保存済みのデザインキットが一覧表示されている状態

3. **03-before-after.png**
   - 適用前と適用後の比較
   - オリジナルと「(変換済み)」レイヤーを並べて表示

4. **04-changes-log.png**
   - 「適用された変更」セクション
   - 変更内容の詳細が表示されている状態

5. **05-real-example.png** (オプション)
   - 実際のデザインワークフローでの使用例
   - キャンペーンLPなどの実際のデザインを変換している様子

## スクリーンショット作成のヒント

- 明るい背景を使用（読みやすさ向上）
- 重要な部分は赤枠などで強調
- 実際のデザインサンプルを用意（ダミーデータでも可）
- UIの全体像がわかるように撮影
- 高解像度で撮影（Retinaディスプレイ対応）

## 撮影後の確認

- [ ] すべての画像が1200x900px以上か確認
- [ ] ファイルサイズが大きすぎないか確認（1枚あたり2MB以下推奨）
- [ ] 個人情報や機密情報が含まれていないか確認
- [ ] 画像が鮮明で読みやすいか確認
