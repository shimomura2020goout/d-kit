✨ D-kit

Transform your existing designs by applying styles from any design kit

🎨 Design Systems ⚡ Productivity 🔄 Style Transfer 📦 Free & Open Source

📖 概要

D-kitは、既存のデザインを選択したデザインキット（Figma Communityファイルなど）のスタイルで自動的に置き換えるFigmaプラグインです。デザインシステムの適用、ブランドリニューアル、スタイルガイドの変更などを効率化します。

🎯 こんな方におすすめ
  • ランディングページのリブランディングを素早く行いたいキャンペーンデザイナー
  • 複数のブランドバリエーションを管理するデザインチーム
  • Figma Communityのデザインシステムを活用するデザイナー
  • 異なるスタイルの方向性を試してみたい方

✨ 主な機能

📦 デザインキットのエクスポート

任意のFigmaファイルからカラースタイル、テキストスタイル、エフェクト、コンポーネント情報を保存。一度保存すれば、どのファイルからでも利用可能です。

🎯 自動スタイルマッチング

近接アルゴリズムを使用して色をインテリジェントにマッチング。フォントサイズに基づいてテキストスタイルを適用します。

📊 変更履歴の可視化

デザインキット適用後に何が変更されたかを詳細に表示。適用された変更を一覧で確認できます。

🔒 非破壊ワークフロー

オリジナルレイヤーの複製を作成するため、いつでも元に戻せます。安心して試行錯誤できます。

💾 ローカルストレージ

デザインキットはローカルに保存され、すべてのFigmaファイルで利用可能。ネットワークアクセス不要です。

⚡ 高速処理

効率的なアルゴリズムにより、大量の要素でも高速に処理。ストレスフリーなワークフローを実現します。

🚀 使い方

初回セットアップ: デザインキットを保存

デザインキットを初めて使う場合のみ、以下の手順で保存してください：

  1. デザインキットとして使用したいFigmaファイルを開く（Figma Communityから複製したファイルでもOK）
  2. プラグインを起動: Plugins > D-kit
  3. 下部の「⚙️ デザインキットを保存（初回のみ）」セクションを展開
  4. 「現在のファイルをデザインキットとして保存」ボタンをクリック
  5. 成功メッセージが表示されれば完了
💡 ヒント: この操作は、新しいデザインキットを追加する場合のみ必要です。一度保存すれば、どのFigmaファイルからでも使用できます。

メインワークフロー: デザインキットを適用

  1. 作業ファイルを開く（既にデザインが作成されているファイル）
  2. プラグインを起動: Plugins > D-kit
  3. ドロップダウンから保存済みのデザインキットを選択
  4. Figmaキャンバスでレイヤーを選択（フレーム、グループ、セクションなど）
  5. 「選択レイヤーにデザインキットを適用」ボタンをクリック
  6. 元のレイヤーの横に「(変換済み)」という名前の複製が作成されます
  7. 「適用された変更」セクションで変更内容の詳細を確認

🔧 技術仕様

主要な処理アルゴリズム

処理 アルゴリズム 詳細
カラーマッチング ユークリッド距離 RGB色空間で最も近い色を選択
テキストスタイル フォントサイズ比較 最も近いフォントサイズのスタイルを適用

💻 開発情報

セットアップ手順

# リポジトリをクローン
git clone https://github.com/yourusername/d-kit.git
cd d-kit

# 依存関係をインストール
npm install

# TypeScriptをビルド
npm run build

# または、開発中は自動ビルド
npm run watch

Figmaへのプラグイン追加

  1. Figma Desktop Appを起動
  2. メニューから Plugins > Development > Import plugin from manifest... を選択
  3. このプロジェクトの manifest.json ファイルを選択
  4. プラグインが開発プラグインとして追加されます

制限事項

  • Figma Plugin APIの制約により、Community fileに直接アクセスはできません
  • プラグインは現在開いているファイルのローカルデータのみ操作できます
  • 複雑なグラデーション、画像フィルなどは部分的にしかサポートされません
  • パフォーマンス: 大量の要素（1000+）がある場合、処理に時間がかかる場合があります
