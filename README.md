# D-kit

Figmaプラグイン：既存のデザインを選択したデザインキットのスタイルで置き換える

## 概要

D-kitは、デザインチーム向けのFigmaプラグインです。既存のデザインを選択したデザインキット（Figma Communityファイルなど）のスタイルで自動的に置き換えることができます。

### 主な機能

- **デザインキットのエクスポート**: カラー、テキストスタイル、エフェクト、コンポーネント情報を保存
- **スタイルの自動適用**: 選択したレイヤーに保存済みデザインキットを適用
- **変更内容の可視化**: 適用された変更点を一覧表示
- **非破壊編集**: 元のレイヤーを保持し、複製に適用

## セットアップ手順

### 前提条件

- Node.js（v14以上推奨）
- Figma Desktop App

### インストール

1. リポジトリをクローンまたはダウンロード

```bash
git clone <repository-url>
cd 202510-figma-plugin-trace-kit
```

2. 依存関係をインストール

```bash
npm install
```

3. TypeScriptをビルド

```bash
npm run build
```

または、開発中は自動ビルド:

```bash
npm run watch
```

### Figmaへのプラグイン追加

1. Figma Desktop Appを起動
2. メニューから `Plugins` > `Development` > `Import plugin from manifest...` を選択
3. このプロジェクトの `manifest.json` ファイルを選択
4. プラグインが開発プラグインとして追加されます

## 使い方

### 初回のみ: デザインキットを保存

デザインキットを初めて使う場合のみ、以下の手順で保存してください：

1. デザインキットとして使用したいFigmaファイルを開く
   - Figma Communityから複製したファイルでもOK
   - カラースタイル、テキストスタイル、エフェクトが定義されているファイル

2. プラグインを起動: `Plugins` > `Development` > `D-kit`

3. 下部の「⚙️ デザインキットを保存（初回のみ）」セクションを展開

4. 「現在のファイルをデザインキットとして保存」ボタンをクリック

5. 成功メッセージが表示されれば完了

**注意**: この操作は、新しいデザインキットを追加する場合のみ必要です。一度保存すれば、どのFigmaファイルからでも使用できます。

### メインワークフロー: デザインキットを適用

1. **作業ファイルを開く**（既にデザインが作成されているファイル）

2. **プラグインを起動**: `Plugins` > `Development` > `D-kit`

3. **デザインキットを選択**
   - ドロップダウンから保存済みのデザインキットを選択
   - キットの機能情報（カラー数、テキストスタイル数など）が表示されます

4. **Figmaキャンバスでレイヤーを選択**
   - 変換したいフレーム、グループ、セクションなどを選択
   - 複数選択も可能

5. **「選択レイヤーにデザインキットを適用」ボタンをクリック**

6. **結果を確認**
   - 元のレイヤーの横に「(変換済み)」という名前の複製が作成されます
   - 元のデザインと比較しながらブラッシュアップできます
   - 「適用された変更」セクションで変更内容の詳細を確認できます

7. **必要に応じて微調整**
   - 気に入らなければ複製を削除して、再度適用できます
   - 元のレイヤーは常に保持されます（非破壊編集）

## 技術仕様

### プロジェクト構造

```
202510-figma-plugin-trace-kit/
├── manifest.json          # プラグイン設定
├── package.json           # npm設定
├── tsconfig.json          # TypeScript設定
├── ui.html                # UIのHTML（CSSを含む）
└── src/
    ├── code.ts            # メインロジック（型定義を含む）
    └── code.js            # ビルド済みJavaScript
```

### 主要な処理

#### エクスポート機能

- `figma.getLocalPaintStyles()`: カラースタイルを取得
- `figma.getLocalTextStyles()`: テキストスタイルを取得
- `figma.getLocalEffectStyles()`: エフェクトスタイルを取得
- `figma.clientStorage.setAsync()`: ローカルストレージに保存

#### 適用機能

- 選択されたノードを複製
- カラーマッチング: ユークリッド距離で最も近い色を選択
- テキストスタイルマッチング: フォントサイズが最も近いスタイルを適用
- エフェクト適用: デザインキットのエフェクトを適用
- 角丸の正規化: 一般的な値（4, 8, 16pxなど）に丸める

### データ構造

```typescript
interface DesignKit {
  name: string;
  sourceFile: string;
  exportedAt: string;
  colors: ColorStyle[];
  textStyles: TextStyleData[];
  effects: EffectStyle[];
  components: ComponentData[];
}
```

## 制限事項

- Figma Plugin APIの制約により、Community fileに直接アクセスはできません
- プラグインは現在開いているファイルのローカルデータのみ操作できます
- 複雑なグラデーション、画像フィルなどは部分的にしかサポートされません
- パフォーマンス: 大量の要素（1000+）がある場合、処理に時間がかかる場合があります

## トラブルシューティング

### プラグインがビルドできない

```bash
# node_modulesを削除して再インストール
rm -rf node_modules
npm install
npm run build
```

### スタイルが適用されない

- デザインキットにカラースタイルやテキストスタイルが定義されているか確認
- 選択したレイヤーに適用可能なプロパティがあるか確認

### フォントエラーが発生する

- 使用されているフォントがシステムにインストールされているか確認
- フォントが見つからない場合は、代替フォントが使用されます
